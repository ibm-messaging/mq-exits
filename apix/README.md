This directory contains examples of API Exits

For more information about API Exits, see the [MQ
documentation](https://www.ibm.com/docs/en/ibm-mq/latest?topic=services-writing-compiling-api-exits-multiplatforms)

There is further discussion of various details in an FAQ article [here](https://marketaylor.synology.me/?p=700).

## Contents
* otel - Context Propagation from OpenTelemetry-instrumented C/C++ applications
* nootel - Remove RFH2 structure caused by OTel-instrumented processing, when app is not expecting it
